# Nori Page portfolio

Static site with clean URLs (`/ufo/`, `/about/`). Paths are root-relative, so preview it with a local server rather than opening files directly:

```
python3 -m http.server 8000
```

then visit http://localhost:8000.

Pages: index (work reel), about, and case studies for Fury, Sea Maui, Vagabond Cruise, UFO, Mexico Whale Shark, Aster Lane Floral, Wanderlust and Nerve.
