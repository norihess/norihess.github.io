Overview

Design goal

The primary goal was to simplify how visitors explore and book a whale shark tour. The existing activity setup made the available options feel more complicated than necessary, so the new design focused on clearer tour organization, stronger hierarchy, and a more direct path to booking.

Key priorities
  • Introduce a completely new visual direction
  • Simplify how tours are presented
  • Make the booking journey easier to follow
  • Keep primary calls to action prominent
  • Use TripAdvisor and Google reviews to build trust
  • Preserve useful content within a clearer structure
Design approach

The homepage uses immersive marine photography to establish the experience, followed by simplified tour options and clear booking actions.

Prominent review content helps reassure travelers before they commit, while the streamlined page structure reduces unnecessary decisions between discovering a tour and checking availability.
